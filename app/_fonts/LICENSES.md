# Bundled fonts

These Latin-subset WOFF2 files are loaded with `next/font/local` in `app/layout.tsx`, so building UserTasks never downloads fonts.

| File | Font | Copyright | Licence |
|---|---|---|---|
| `inter-latin-opsz-wght.woff2` | Inter (variable: weight, optical size) | The Inter Project Authors (https://github.com/rsms/inter) | SIL Open Font License 1.1 |
| `jetbrains-mono-latin-wght.woff2` | JetBrains Mono (variable: weight) | The JetBrains Mono Project Authors (https://github.com/JetBrains/JetBrainsMono) | SIL Open Font License 1.1 |
| `fraunces-latin-wght.woff2` | Fraunces (variable: weight) | The Fraunces Project Authors (https://github.com/undercasetype/Fraunces) | SIL Open Font License 1.1 |

The SIL Open Font License 1.1 is at https://openfontlicense.org. The fonts may be bundled and redistributed with software; they may not be sold on their own.
